# ÁGIL Scanner — Android

Aplicativo Android para digitalizar exclusivamente:

1. Relatório de Configuração
2. Relatório de Ativo
3. Página de Estatística

## O que a versão 1 faz

- solicita o número do chamado;
- abre o scanner oficial do Google ML Kit;
- detecta as bordas do papel;
- corrige perspectiva e permite ajustar o corte;
- aceita múltiplas páginas por documento;
- gera PDF;
- salva com nome automático;
- permite enviar cada PDF individualmente pelo WhatsApp;
- permite enviar os PDFs digitalizados juntos pelo WhatsApp;
- mostra o progresso: 0/3, 1/3, 2/3 ou 3/3.
